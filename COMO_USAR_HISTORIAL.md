# 🚀 Cómo Usar el Historial de Conversaciones

## ⚡ Guía Rápida (30 segundos)

### 1️⃣ Ver tus conversaciones guardadas
```
Click en "Historial (X)" → Se abre panel con todas tus conversaciones
```

### 2️⃣ Volver a una conversación anterior
```
Abre historial → Click en la conversación → Se carga completa
```

### 3️⃣ Empezar una nueva conversación
```
Click en "Nueva Conversación" → Chat limpio para nuevo tema
```

### 4️⃣ Eliminar una conversación
```
Abre historial → Click en 🗑️ → Confirmar → Eliminada
```

---

## 🎯 Casos de Uso

### Caso 1: Continuar donde te quedaste
```
1. Usas el chatbot hoy
2. Cierras la página
3. Vuelves mañana
4. Tu conversación sigue ahí ✅
```

### Caso 2: Múltiples temas
```
1. Preguntas sobre becas
2. "Nueva Conversación"
3. Preguntas sobre pensiones
4. "Nueva Conversación"
5. Preguntas sobre apoyos
→ Tienes 3 conversaciones separadas
```

### Caso 3: Buscar información anterior
```
1. "Historial"
2. Buscas la conversación sobre becas
3. Click para cargarla
4. Revisas la información
```

---

## 💡 Tips Importantes

### ✅ Haz esto
- Usa "Nueva Conversación" para temas diferentes
- Revisa el historial para recordar información
- Elimina conversaciones que ya no necesites
- El título te ayuda a identificar cada conversación

### ❌ Evita esto
- No uses "Limpiar" si quieres guardar la conversación
- No limpies el caché del navegador si quieres mantener el historial
- No uses la misma conversación para temas muy diferentes

---

## 🔍 Identificar Conversaciones

Cada conversación muestra:

```
┌─────────────────────────────────────────────┐
│ Soy madre soltera con dos hijos, ¿qué...  │ ← Título
│ 💬 12 mensajes  🕐 12 may, 20:30      [🗑️] │
│    ↑ Cantidad    ↑ Fecha/hora    ↑ Eliminar│
└─────────────────────────────────────────────┘
```
